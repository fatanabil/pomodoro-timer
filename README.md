# Pomodoro Timer ⏲️🍅

A web-based application to help you stay focused using the Pomodoro Technique — simple, flexible, and effective for boosting productivity.

---

### 🌱 What is the Pomodoro Technique?

The Pomodoro Technique was developed by Francesco Cirillo in the late 1980s. The idea is simple:

1. Break work into short focus intervals (traditionally 25 minutes).
2. Follow each with a short break (~5 minutes).
3. After four Pomodoros, take a longer break (~15–30 minutes).

---

Key Benefits:
✅ Boosts focus and reduces distractions.
✅ Makes large tasks feel manageable.
✅ Prevents burnout with regular breaks.
✅ Helps fight procrastination by lowering the “starting barrier.”
✅ Creates a sense of progress and achievement after each session.

💡 **Note**: _Everyone is different! While 25/5 works for many, some prefer longer focus sessions (like 50/10 or 90 minutes). This app lets you customize it to your style._

---

### ✨ Features

-   Two phases
    -   Focus session
    -   Break session
-   Custom durations
    -   Adjust focus and break times to your liking
-   Notifications
    -   Enable/disable browser notifications when a session ends.
-   PWA support
    -   Install it as a Progressive Web App (PWA) on desktop or mobile for quick access.

---

Simple but flexible — _classic 25/5 Pomodoro or fully customized cycles._

### 📖 Getting Started

```bash
# Clone the repo
git clone https://github.com/fatanabil/pomodoro-timer.git

# Move into the project folder
cd pomodoro-timer

# Install dependencies
npm install

# Run locally
npm run dev
```

Open the app in your browser and start your first Pomodoro! 🍅

---

### 🧑‍💻 How to Use

1. Set your preferred focus & break durations.
2. Start the timer — focus during the session, rest during the break.
3. Enable notifications if you want reminders when sessions end.
4. (Optional) Install the app as a PWA for a native-like experience.

---

### 🔑 Pro Tips

1. Start with the classic 25/5 cycle, then experiment to find your sweet spot.
2. Use breaks to step away from your desk (stretch, hydrate, or breathe).
3. Track how many Pomodoros you complete in a day to measure productivity.
